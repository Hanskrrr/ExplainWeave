# 实现状态 — 0.1.0 开发预览

## 已实现

- TypeScript workspace；Obsidian 桌面插件；React Notebook 与连续文章视图；CodeMirror 编辑器。
- 显式节点身份与版本；受保护的 frontmatter、代码、公式边界；初次启用前预览；按安全二级标题边界初分节点。
- 节点插入、编辑、移动、拆分、合并、删除；问题、追问、阅读位置及返回主线。
- 手动关联具体解释片段；按照当前阅读位置计算覆盖；问题、父问题、原段落或回答变化后进入待检查。
- 伴随元数据、草稿持久化、外部变更对账、带意图记录的两文件恢复；内容撤销不会覆盖后来不同的正文。
- 离线模拟生成；DeepSeek / Claude API 流式后端、取消和可用的 token 用量；API 密钥仅会话保存。
- Cowork 任务包、官方深链接、严格校验返回文件；导入结果作为候选草稿。
- 构建脚本、独立测试 Vault、CI、单元/集成测试与 Chromium 宽窄窗测试。

## 验证边界

直接模型后端使用协议夹具验证，未使用真实账户发起付费调用。Cowork 的数据协议经过测试，尚未在真实客户端完成来回交接。浏览器验证使用真实 UI、核心、控制器和内存文件系统；并未替代 Obsidian 原生 Markdown/公式渲染、文件事件和操作系统输入法验证。

存储使用单活动写入者。检测到已知冲突会拒写，但文件系统没有跨应用原子 compare-and-swap，因此不能宣称支持多个编辑器/设备同时写入。文件重命名时尝试迁移伴随文件；复杂同步冲突须保留原文件处理。

撤销记录目前保留在打开的笔记会话中，重启或外部更新后不能继续撤销旧操作；正文、问题、阅读位置和已收取草稿可以恢复。生成中的草稿在完成、取消或正常关闭时保存，进程突然退出可能丢失尚未保存的流式片段。

## 后续重点

1. 在真实 Obsidian 测试 Vault 验证原生渲染、中文输入法、文件重命名和插件卸载生命周期。
2. 配置真实 API 后完成服务调用与错误路径验证；实测 Cowork 来回交接。
3. 为 AI 覆盖判断设计带证据的建议操作，实现自动发现缺失解释、部分覆盖和人工纠正；当前关联操作用于验证数据与交互，不是“我理解了”打勾。
4. 把上下文日志接入实际任务，加入局部上下文选择、版本增量和检查点；当前 API 调用仍使用当前文章快照，不承诺编辑中间内容后保留缓存前缀。
5. 接 Codex App Server 与 Claude Agent SDK；此版只实现直接模型 API 和 Cowork 客户端交接。

模型是否语义上解释充分、跨文章依赖、多条阅读路线、持久撤销历史与多设备协作，均不能视为已完成。
